# Home Ware

Home Ware is a simple online shopping website for home products.

## Features
- View products
- Search products
- Sort products
- Add products to cart
- Responsive design

## Technologies Used
- React
- 
- Vite
- Tailwind CSS

## How to Run

1. Install dependencies:

   npm install

2. Start the project:

   npm run dev

## Purpose

This project was created to practice front-end web development.
